# 工资与生活

一个温暖、轻量的中文工资与生活开销计算器。输入到手月薪，就按 **22 天 × 每天 8 小时**显示时薪。按需修改时间、添加支出，再根据目标总存款和已有存款，估算还要积累多久。

## 使用方式

1. 填写 **到手月薪**。税前「薪资」仅用于记录，不参与任何计算。
2. 展开「调整时间」，修改工作天数、每日工作小时、每日往返通勤分钟和午休分钟。清空工作天数或小时分别恢复 22 天、8 小时；显式填写 0 会提示修正。
3. 展开「每月固定支出」，按月填写房租、通勤、水电和自定义项目。修改或删除项目后立即重新计算。
4. 第三部分填写伙食等其他生活开支，再输入目标总存款、已有存款和剩余负债总额，查看每月结余、目标差额和预计所需年月。同一笔费用只填一次。
5. 第四部分填写希望几年几个月达到目标，查看每月目标预留、可花额度和日均参考。期限默认留空，目标达成后无需继续预留。
6. 页面底部可复制首页链接、扫码或保存通用分享图，均不包含个人账本。
7. 如需保留数据，主动开启「在本机记住」。关闭开关或点击「清空填写」会删除本站保存的数据。

## 计算口径

- 工作时薪 = 到手月薪 ÷（每月工作天数 × 每天工作小时）。
- 每天工作时间 **不含午休**；每日往返通勤和午休都按分钟填写，另外计入占用时间。
- 含通勤与午休的时薪 = 到手月薪 ÷〔工作天数 ×（工作小时＋往返通勤分钟 / 60＋午休分钟 / 60）〕。
- 月度余额 = 到手月薪 − 已填写的月度支出。
- 每小时留下的钱 = 月度余额 ÷ 含通勤与午休的月度总时间。
- 每日参考额度 = 正数月度余额 ÷ 30，属于整月平均，并非从今天起的剩余预算。
- 赤字显示本月缺口和每小时缺口；可自由安排及每日额度显示为 0。
- 金额按分计算，时薪使用完整精度后再保留两位小数。
- 未填写的费用不扣除，不自动添加储蓄、餐费或应急金。
- 第三部分每月结余 = 第二部分原始月度余额 − 其他生活开支。第二部分若已为赤字，继续按负数扣减，不从零开始扣。
- 目标差额 = max(目标总存款 + 剩余负债总额 − 已有存款, 0)，已有存款和负债未填均按 0。
- 负债包括房贷、车贷、信用卡等剩余欠款合计，按“还清已填负债后保有目标存款”估算。负债不再从每月结余扣一遍；计入该总额的同一笔欠款也不应重复填写为月支出。采用不计未来利息的简化模型，不计算各类贷款的还款计划。仅测算还清债务时，可将目标存款填为 0。
- 按整月结余存入所需月数 = ceil(目标差额 ÷ 每月结余)。已有存款覆盖目标加负债时为 0；每月没有正数结余时不生成期限。
- 总月数先向上取整，再显示为几年几个月：40 个月为 3 年 4 个月，12 个月为 1 年 0 个月，不足一年只显示月份。
- 等效工作天数 = ceil(目标差额 ÷ 每月结余 × 每月工作天数)，使用未取整的月数折算。
- 目标估算假设收入、全部填写的支出保持不变，每月结余全部存入，不计算利息。工作天数是预算折算，不代表实际到账或完成日期。

例如到手 10,000 元、固定支出 4,000 元、伙食等生活费 2,000 元，每月结余 **4,000 元**。目标总存款 12,000 元、已有 2,000 元，还差 **10,000 元**；按整月结余存入需 **3 个月**，按每月 22 个工作日折算为 **55 个工作日**。

例如到手 8,000 元，房租 2,000、水电 200、通勤费 300，月度余额为 **5,500 元**，每日参考 **183.33 元**。到手 10,000 元、默认工时下时薪为 **56.82 元**；往返通勤 30 分钟、午休 45 分钟后为 **49.14 元**。

## 留给自己花的钱

- 指定月数 = 年数 × 12 + 月数。年数为 0–9999 的整数，月数为 0–11 的整数；只填一项时另一项按 0，合计至少 1 个月。
- 空期限不生成额度，也不自动使用最快达标时间；非法期限只影响第四部分。
- 每月目标预留（分） = ceil(目标差额（分）÷ 指定月数)。
- 可花额度 = max(每月结余 − 每月目标预留, 0)。每月短缺 = max(每月目标预留 − 每月结余, 0)，使用原始结余，保留已有赤字。
- 日均参考 = 可花额度 ÷ 30，展示四舍五入到分，以每月额度为准。
- 目标已达成时预留为 0，不需要填写期限；收入或支出未填有效时不显示可花额度。
- 示例：月结余 5,000 元、差额 72,000 元、期限 2 年，每月预留 **3,000 元**，可花 **2,000 元**，日均 **66.67 元**。最快估算仍按全部结余用于目标计算。

## 本地运行

项目没有外部运行依赖，也无需安装 npm 包。安装 Node.js 后运行：

```sh
npm start
```

打开终端输出的本地地址。也可以用任何静态服务器提供 `dist/` 目录。

```sh
npm test
```

测试覆盖默认值、用户覆盖、清空回退、显式零值、午休与通勤单位、分组支出、舍入、赤字、目标差额、达到目标、无结余以及本地保存兼容。

## 源码与部署

- `dist/index.html`：四部分输入和月度小结。
- `dist/styles.css`：手机与电脑的手账式布局。
- `dist/calculate.mjs`：独立计算和本地存储逻辑。
- `dist/app.mjs`：交互与结果更新。
- `dist/share.mjs`：固定首页链接与复制失败处理。
- `dist/share-qr.png` / `dist/share-card.png`：预生成通用分享素材，无个人金额。
- `scripts/generate_share_assets.py`：可选素材生成工具，依赖 Pillow、NumPy、opencv-python 和中文字体；不属于网站运行依赖。支持 `--out-dir`、`--serif-font`、`--sans-font`。默认使用 macOS 宋体与黑体字体集合；其他字体可能需调整字体索引。

将完整 `dist/` 上传到任意静态网站托管服务即可运行，无后端或数据库。若使用 Sites，自行部署时请注册自己的站点，并使用自己的 `.openai/hosting.json` 项目 ID。

## 数据与隐私

所有工资和支出只在浏览器内计算，不请求计算接口、不上传、不拼入网址；不使用统计脚本、广告或第三方字体。默认不保存个人数字，只有主动开启后才写入当前浏览器的 localStorage。网站托管服务仍可能记录访问请求，不包含表单里的工资和支出。
